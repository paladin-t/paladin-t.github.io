This update introduces a new code debugger. Combined with the existing VRAM
debugger, you can now fully debug both code and assets within an integrated
environment. You can set breakpoints in your code (whether in BASIC or ASM),
during runtime the emulator will pause program execution at the appropriate
moment, allowing you to inspect and debug variables, threads, objects, or
hardware assembly through the inspector. The original text rasterizer was a
general-purpose function supporting variable-width, unaligned text rendering.
This update introduces an optimized rasterization path for 8x8, tile-aligned
text, speeding up regular font rendering. It also optimizes symbol exports and
aliases, along with various other improvements and fixes.
